# 一次性迁移（v1 旧模型 → 新存储）

前提：已读 `SKILL.md`。**只跑一次**；**必须先于交接**。**v2 → 新不在技能能力内**（v2 从未发布；仅本仓一次性内部转换）。

## 核心

迁移**不强切旧文档**——那正是旧模型「互斥边界」的根源。迁移只产**两种落点**：
- **条目**（能**廉价、确定**地切）→ `actions/` / `pitfalls/` / `decisions/`；
- **候选 / 引用节点**（**切不动**的源 / 位点）→ `unconfirmed`（未能确认，持久可追）。

→ **迁移不需要「确定性抽取」**。

## 步骤

0. **登记源集（先于一切）**：`handoff scope scan` 出**机械候选** → **用户确认 / 补充** → `handoff scope add <path|glob>` 逐条登记。得「**本次迁移源集**」。
   - **无需 `init`**：`scope add` / `import` 会自建骨架（`init` 仅在 index 不存在时可用，**非幂等**）。
   - 完备性口径：**「登记表内完备」，非项目级**；表外**契约上不存在**（`scope scan` 只提议）。
   - `scope` 是**持久登记表**：迁移时＝源集，**迁移后应＝活体源**（未决项可能落在哪）。归档致旧源失效的登记项由 `migrate` **自动剪除**（步骤 2），**须补登活体源**（步骤 3）。
1. **清点（agent，模糊解析）**：读**登记表内**旧件，产出**迁移清单 JSONL**（＝ `export` 格式，见 `SKILL.md` §export）：
   - 每条 `{"_kind":"entry|doc","_slot":…, 分区键…, 字段…}`；切不动 → `{"_kind":"entry","_slot":"unconfirmed","summary":…,"src":"<路径#锚>"}`。
   - **来源覆盖**（至少）：`HANDOFF.md` 正文本身；`HANDOFF-ARCHIVE/` 下**全部** `.md`（含子目录 `pits/*.md` 与非标准命名）；ARCHIVE 之外卷（`docs/backlog.md` 等）；仓外 tracker（读不到→`unconfirmed`）。
   - **决策**：ADR（如 `docs/decisions/*.md`）→ **登记并迁入 `decisions/`**（`_kind:"doc"`），勿只落 `unconfirmed`。
2. **落存储 + 归档（一体，勿拆）**：
   ```sh
   sh <技能>/scripts/migrate.sh [--store .handoff] --archive <源件>… <清单>
   ```
   = `import`（自建骨架 + 单一写路径 + 校验）→ `check` 门禁 → 归档旧件到 `.handoff/legacy/<日期>/`（**默认归档不删**）→ `scope prune`（剪掉因归档而失效的登记项）。
   - **导入失败即中止**（不归档、不给「假 OK」）。**勿单跑裸 `import` 再单跑归档**——那会留下「空骨架 + `check` 看似 OK」的假成功。
   - 清单**首行须 meta** `{"_format":"handoff",…}`（缺则拒）。
   - 条目**可省略 `id` 与日期**：缺 `id` → 脚本分配；缺 `created`/`closed` → 脚本盖迁移日（**不靠 LLM 编造**）。`closed` 条目可给 `_type`（`t|p|d|c|q`）代替 `id`。
   - `_slot` 只接受 `actions/pitfalls/commands/unconfirmed/closed`（entry）与 `decisions/单文件`（doc）；**未知槽报错不静默**。
   - 目标已存在条目 → `import` 拒绝；`--force` **先重置**再导入（非增量追加）。**删除旧件须用户显式授权**。
3. **登记活体源**：`handoff scope add <path|glob>`——迁移后**未决项可能落在哪**（活体卷 / 看板）；`check` 校每条登记可解析。
4. **钉约定**：确保 `AGENTS.md` 含「未决项只写 `.handoff/`」节（**无则新建**；机械锚幂等）。
5. **清扫引用端**（根因闸，非收尾美化）：迁移只动**存储**，坏掉的是**别处指向旧布局的写指令**。全仓搜旧模型的**易失布局签名**（节号、把旧卷名当写入口的行）——含本仓其它文档、脚本、`AGENTS.md`、**技能正文**——逐条改指「**功能 + 新槽**」（如「决策账本 → `handoff add decision`」），**不按旧节号逐字翻译**（翻译只是把耦合点从节号换成槽名，下次改版再废一次）。
   - **判据**：只有**指令形**（动词 + 旧写入口，如「与 §3 同步」）算墓碑；**提及形**（为探测／路由／映射而列举旧模型）**保留原样**——那些是迁移能力自身的一部分。
   - **须在覆盖声明之前**：漏扫＝把「已迁」交出去，而别处的写指令仍往不存在的卷里写。
   - 出处（真源 t000014）：三件技能正文（`decision-log` / `stage-spec` / `session-health`）在 09-20 迁移后仍写着「`HANDOFF §3/§5` 同步」，**迁移当时无人发现**——旧卷在 `.gitignore` 里是私有件，迁移提交的 diff **两头都不完整**（既不含被删的旧节，也不暴露孤儿引用）；当时的检测器全部建模**技能名**同一性，无一覆盖**基础设施指称**失效。本步即那次事故的修法。
6. **出覆盖声明**：源集内每个候选都已判（入账 or `unconfirmed`）＋ 本步引用端清扫的**搜到／改掉的计数**。

## 清点判据

- **指针 vs 实条目**：不入账的**仅限「纯重定向行」**（整行语义＝指向某卷，形状 `<桶/领域> (×N)? → <路径|锚>` 且无动作子句）。**不凭 `→` 符号判**（`detached → master`、`触发 → 后果` 是实条目）；**只作用视图层 `HANDOFF.md`**，卷内 `→` 视为语义。**判不准倾向入账**。
- **去重范围**：只合并**同 type ∧ 同源**；跨 type 默认不合并。明确被取代 → 迁 `closed`，`outcome:"被 <src> 取代"`。
- **粒度契约**：一条＝**可独立翻转完成态的最小单元**；**默认取更细**。优先级：完成标记 `[ ]/[x]/✓/✗/☑` → 表格数据行 → 命名块（仅单一不可分才 1 条，否则逐项）→ 顶层 bullet → prose（按 `；/、/·`/`①②` 拆）。**混合状态块必须逐项**。
- **状态判定**（从宽）：勾选标记 → 小节名 → 条目内词 → **不确定记 `open`**。
- **日期**：`created`/`closed` 尽力从原文取（卷头 / 分节 / 内联 / 表格「证据」列）并透传；**取不到 → 留空，由脚本盖迁移日**（不编造）。
- **清单 vs 模板**：活体待办入账；规范清单 / 模板 / DoD / 已封版快照按名 / 目录模式排除，**不静默**（记 `unconfirmed`）。

## 类型映射

`backlog` 未决→`actions`(`t`)；`backlog` 已决 / `done.md`→`closed`(`t`)；`pits`→`pitfalls`(`p`)（已修→closed）；`decision`→`decisions`(`d`)；`cycles`/周期→`closed`(`q`)；切不动→`unconfirmed`(`u`)。

**单文件槽（S1/S2/S9）**：`HANDOFF.md §1 元信息`→`summary`；`§2 当前状态`→`status`；**退出判据 / DoD**→`exit`（清单 `_kind:"doc","_slot":"summary|status|exit","content":…`）。**有则迁，无则留空**（缺≠错）。迁移后增量更新用 `handoff set <status|summary|exit>`。

**坑状态按节判**：**按卷内小节**逐一判——`未修 / 活体 / 现行` 节→`pitfalls`(**open**)；`已修 / 已裁决 / 不做` 节→`closed`(`p`)。`pits.md` 常是**混合卷**（同名文件含两节），故**按节不按卷**；**不因单条 fix commit 翻状态**。

**`scope` 活体源口径**：`scope` 只登**能承载未决项（待办 / 未完成）的仓内活体卷**——backlog / plan / roadmap / 待办清单 / issue 清单 / 挂账 review。
- **不登**：报告与审计产物、反馈与快照、会话日志、规范 / 参考 / DoD / `AGENTS.md`、设计规格、维护流水、**store 自身（`.handoff/**`）**（它就是真源）。
- **决策源不登**：`docs/decisions/**`、`docs/adr/**`、决策账本等是 `decisions/` 的**迁移源**，迁入后不再是活体未决源（其内若有未决，如 `proposed`，应以条目 / `unconfirmed` 入账）。
- **按内容角色判，不按目录名**：如 `.scratch/…/issues/**` 若承载未决则登；`docs/audits/**` 即使在新目录下也不登。
- **无则留空**（合法）。

## 硬约束

- **源集内逐条清点，列不全不归档 / 删**（session.md 6→2 事故）；源集外不进契约。
- **迁移＝参照端 + 引用端两头**：只迁存储、不清扫别处的旧布局写指令（步骤 5），交付的是半截迁移。
- 已决项也完整迁入 `closed`（供追溯）。
- **条目只经 `handoff import`**；勿手搓 `.handoff/`。
- **旧指纹 `.handoff/fp.*`** 属已删机制：迁移时**移出 / 删**，勿与新槽混放。
