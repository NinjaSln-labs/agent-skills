# AGENTS.md 交接块（标准源 · 由 project-handoff 持有）

> **这块是唯一源。** 每个项目在**自己**启用交接时（`init`）自动写入，块外内容不受影响；
> 若该仓已有 `## 交接` 整节但无标记区，**整节会被整理覆盖**（手写副本被这块接管，
> 节外的其它章节不动，被替换的行数会打印）——留两份等于让 agent 随机选一份。
> 之后用 `agents-block --check` 做字节比对，漂移即 rc=1。
>
> **为什么块里不写命令全路径、也不写死 `python3`**：① 技能装在 `~/.agents/skills/<name>/`，
> 各仓的相对路径不同，写死必然指错；② 解释器随平台而异（Windows 常只有 `python`）。
> 命令的准确形式属于**技能正文**的事（那里写明 Linux/macOS 用 `python3`、Windows 用 `python`），
> AGENTS.md 只留纪律，不留会过期的路径。
> **不要手改本文件里的条目**——改了不会同步到别的仓，而 `--check` 会立刻报漂移。

## 另一档增强（不进块，按需手写）

本仓的判据有唯一定义点且可验证时，可另写：

- 判据的输入必须是落盘证据（命令输出、回执、快照），不是「谁记得上次怎么判的」。
- 判据迭代到线即停：硬失败判据总数与新增条件写在技能的 references 里，不在 AGENTS.md 复制。

## 写这块时的三条纪律（来自 AGENTS-WRITING-GUIDE.md）

1. **不写运行状态**（条目数、发布量、日期）——会过期，且过期无痕迹。
2. **不写具体计数**（「三条命令」）——列举即可，计数一变就假。
3. **不写元话语**（「本节讲什么」）——agent 正读着这个文件，不需要被介绍。
